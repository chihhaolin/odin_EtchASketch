# Etch-a-Sketch — Project Targets

## 核心目標
打造一個瀏覽器版的像素畫圖板，練習 DOM 操作、事件監聽與 Flexbox 排版。

## 必要功能 (Required)

- [ ] T01：用 JavaScript 動態產生 16×16 的方格網格（不可手寫 HTML）
- [ ] T02：網格方格放置於一個 container div 內
- [ ] T03：使用 Flexbox 將方格排列成網格狀
- [ ] T04：滑鼠滑過方格時，方格改變顏色（hover 塗鴉效果）
- [ ] T05：頁面頂部有一個「重設網格」按鈕
- [ ] T06：點擊按鈕後，彈出 prompt 詢問使用者每邊的格數（上限 100）
- [ ] T07：輸入格數後，移除舊網格，產生新網格，總佔用空間不變（960px 寬）
- [ ] T08：推送至 GitHub

## 進階功能 (Extra Credit)

- [ ] T09：每次互動時，方格顯示隨機 RGB 顏色
- [ ] T10：每次互動讓方格加深 10%，10 次後變為全黑（使用 opacity 或 darkening 邏輯）
